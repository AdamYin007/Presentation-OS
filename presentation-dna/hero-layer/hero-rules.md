# Hero Layer Rules V1

> 约束规则——在 Presentation DNA 体系中，Hero Layer 的规则是**强制性的**，Patterns 和 Layouts 必须遵守。

## 规则 1：每页只能有一个 Hero

- ❌ 禁止在一页中并列两个以上核心观点
- ✅ 如果需要表达多个观点，拆成两页或多页
- ✅ 允许一个 Hero Statement + 多个支撑论据（图表、数据、引用）

## 规则 2：Hero Statement 必须在标题位置

- 每页必须有明确的 Hero Statement（即页面大标题）
- Hero Statement 不超过 15 个汉字（不含标点）
- 如果当前标题超过 15 字，必须精简或拆分

## 规则 3：五秒可读

- 听众扫视页面 5 秒内应能复述核心信息
- 实现方式：
  - 大标题 = Hero Statement（字号 >= 36pt）
  - 主视觉 = 唯一核心图形（不堆叠多个图表）
  - 正文补充 = 不超过 3 行

## 规则 4：受众适配

每页 Hero 必须匹配目标听众的决策需求：

| 听众层 | 允许的 Hero 类型 | 禁用的 Hero 类型 |
|--------|-----------------|-----------------|
| 院长/高管 | ROI、效率、成本、愿景 | 技术细节、协议列表 |
| 科主任 | 精度、流程、质控、培训 | 财务模型、融资信息 |
| 信息中心 | 集成、安全、成熟度 | 临床诊断细节、患者故事 |
| 临床医生 | 工作流、精度、MDT | 架构分层、ROI 计算 |
| 学术圈 | 证据、伦理、论文管线 | 商业信息、竞品对比 |
| 投资人/政府 | 市场规模、资质、生态 | 技术实现细节 |

## 规则 5：数字优先

- 所有 Hero 陈述中的定性描述必须转化为定量数据
- ❌ "显著提升诊断效率"
- ✅ "诊断效率提升 500%（50片/h → 300片/h）"
- 例外：品牌宣言页、愿景页可使用定性表述

## 规则 6：从"你获得"出发，不从"我们提供"出发

- ❌ "我们提供 AI 辅助分诊系统"
- ✅ "病理医生每天减少 3 小时无效阅片"
- ❌ "我们的平台支持 HL7/FHIR"
- ✅ "您的 HIS 无需改造即可对接"

## 规则 7：模式选择矩阵

根据演讲场景选择 Hero Pattern：

| 演讲场景 | 推荐 Pattern 类别 | 必选 Pattern |
|----------|------------------|-------------|
| 院长汇报 | Value Proposition + Implementation | H-002, H-006, H-007, H-029, H-032 |
| 科主任汇报 | Technical + Compliance + Implementation | H-004, H-012, H-013, H-019, H-023, H-030 |
| 信息中心汇报 | Technical + Compliance | H-003, H-014, H-015, H-016, H-019, H-031 |
| 学术汇报 | Technical + Compliance + Ecosystem | H-012, H-017, H-020, H-021, H-027 |
| 融资路演 | Narrative + Competitive + Ecosystem | H-001, H-003, H-024, H-034, H-035, H-037 |
| 政府汇报 | Narrative + Competitive + Ecosystem | H-001, H-003, H-024, H-026, H-036 |
| 招投标应答 | Compliance + Competitive + Implementation | H-019, H-020, H-035, H-036, H-029 |

## 规则 8：视觉一致性

- 同一页中，Hero Statement 的视觉权重必须 > 所有支撑元素
- 支撑元素不得与 Hero Statement 争夺注意力
- 颜色使用：Hero 用品牌色，支撑用中性色
- 字号层级：Hero 标题 > 支撑标题 > 正文 > 注释

## 规则 9：过渡连贯

- 相邻页面的 Hero 之间必须有逻辑连接
- 连接方式：
  - 因果：前一页的问题 → 后一页的解决方案
  - 递进：前一页的现状 → 后一页的未来
  - 对比：前一页的传统模式 → 后一页的数字化模式
  - 证据：前一页的主张 → 后一页的数据支撑

## 规则 10：AWE 演讲 OS 特殊规则

针对 AWE 演讲场景的额外约束：

- **时间分配**：每页 Hero 预计展示时间 = estimated_reveal_time_s（见 library.json），总时长需匹配演讲时长
- **互动节点**：每 5-7 页设置一个互动节点（提问/投票/演示）
- **记忆锚点**：关键页必须包含可记忆的视觉元素（大数字、对比图、地图）
- **品牌曝光**：封面(H-001)和结尾(H-033)必须使用品牌主视觉
- **无障碍**：所有数据图表必须提供文字替代描述
