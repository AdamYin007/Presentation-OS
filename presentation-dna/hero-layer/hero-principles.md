# Hero Layer Principles V1

> Hero Layer 是 Presentation DNA 的最顶层抽象——它定义每一页 PPT 应该让听众记住的**唯一核心信息**。

## 一、核心定义

Hero Layer = 每页 PPT 的"英雄观点"（Hero Statement）。它是整页视觉和内容围绕的唯一焦点。

**Hero Statement 公式：**

```
[受众] 在 [场景] 下面临 [问题]，通过 [方案] 实现 [量化价值]。
```

示例：
- "院长在运营决策中缺乏病理科效率数据，通过数字病理平台实现 TAT 缩短 62%，每年节省 280 万元。"
- "病理医生面对日均 200+ 切片，通过 AI 辅助分诊将高危病例检出时间从 48h 缩短至 2h。"

## 二、三大铁律

### 1. One Hero Per Slide（一页一英雄）

每页 PPT 只承载一个 Hero Statement。不允许并列多个核心观点。

- **允许**：一张图 + 一个数字 + 一句话结论
- **禁止**：三个要点并列、两张架构叠加、一段文字加一张图再加一个表格

如果内容超过一个观点，拆成两页。

### 2. Five-Second Rule（五秒法则）

听众在五秒内必须能回答：这一页的核心信息是什么？

检验方法：
- 遮住副标题和正文，只看大标题和主视觉，能否理解核心信息？
- 用一句话概括这一页，听众能否在 5 秒内复述？

**五秒法则落地要求：**
- 大标题 = Hero Statement（不超过 15 字）
- 主视觉 = 唯一支撑元素（一张图 / 一个图表 / 一个数字）
- 正文 = 补充说明（不超过 3 行，每行不超过 20 字）

### 3. Decision First（决策优先）

每一页 Hero 都应该服务于听众的某个决策或判断。

问自己：听完这一页，我希望听众做出什么判断？

- 院长层 → "值得投入预算" / "看到 ROI"
- 科主任层 → "能解决我的痛点" / "提升科室效率"
- 信息中心 → "系统能对接" / "安全合规"
- 学术圈 → "有临床价值" / "数据可信"

**决策映射表：**

| 听众类型 | 核心决策 | Hero 应强调 |
|---------|---------|------------|
| 院长 / 运营 | 投入产出比 | ROI、TAT、成本、规模 |
| 病理科主任 | 工作质量与效率 | 精度、分诊、质控、工作量 |
| 信息中心 | 集成与安全 | 标准、接口、等保、数据流 |
| 临床医生 | 诊疗价值 | 诊断准确性、MDT、患者获益 |
| 科研合作者 | 学术潜力 | 数据量、论文、多中心、伦理 |
| 投资人 / 政府 | 行业地位 | 证��、市场、专利、生态 |

## 三、Hero Statement 写作规范

### 3.1 句式模板

| 场景 | 模板 | 示例 |
|-----|------|------|
| 痛点引入 | "[人群] 正面临 [问题]，导致 [后果]" | "基层医院正面临病理医生短缺，导致 40% 报告超时" |
| 方案展示 | "通过 [方案]，实现 [结果]" | "通过 AI 辅助分诊，实现 98% 高危病例 2h 内上报" |
| 数据证明 | "[数字] 家医院验证，[指标] 提升 [幅度]" | "17 家三甲医院验证，诊断效率提升 3.2 倍" |
| 对比说服 | "传统 [方式] vs 数字化 [方式]：[差距]" | "人工阅片 48h vs AI+专家 2h" |
| 愿景引导 | "从 [现状] 走向 [未来]：[关键转变]" | "从硬件数字化走向 AI 智能化" |

### 3.2 禁忌

- **不要用**："我们提供……"（自嗨式，应改为"你获得……"）
- **不要用**：模糊形容词（"显著""大幅""高效"）→ 改为具体数字
- **不要用**：技术术语堆砌（"基于 Transformer 架构的多模态融合……"）→ 改为业务语言
- **不要用**：超过 20 字的标题

## 四、Hero 与 Presentation DNA 的关系

Hero Layer 是上层约束，向下指导：

```
Hero Layer（原则 + 模式）
    ↓
Patterns（30+ 种页面模式）
    ↓
Layouts（布局模板）
    ↓
Grammar（叙事语法）
```

- 每个 Pattern 对应一个或多个 Hero Statement
- 每个 Layout 服务于一个 Hero 的视觉表达
- 每个 Grammar 章节由若干 Hero 串联成完整叙事

## 五、质量检查清单

在交付每页 PPT 前，逐项确认：

- [ ] 本页是否只有一个 Hero Statement？
- [ ] Hero Statement 是否在 15 字以内？
- [ ] 听众能否在 5 秒内说出本页核心信息？
- [ ] 本页 Hero 是否服务于目标听众的某个决策？
- [ ] 是否有具体数字支撑（而非模糊形容词）？
- [ ] 主视觉是否唯一且与 Hero 高度匹配？
- [ ] 是否避免了技术术语堆砌？
- [ ] 是否从"我们提供"改为"你获得"？
