# Presentation Pattern Library V1

## Pattern 001 Hero Statement
用途：封面或核心观点页
结构：一句强观点 + 副标题 + 大留白

## Pattern 002 Executive Three Takeaways
用途：高层摘要
结构：三个结论卡片

## Pattern 003 Why Now
用途：解释项目紧迫性
结构：趋势 + 压力 + 机会

## Pattern 004 Pain Point Cluster
用途：现状痛点
结构：3-5 个痛点卡片

## Pattern 005 From-To Transformation
用途：转型逻辑
结构：传统模式 → 数字化模式 → 智能化模式

## Pattern 006 Platform Hub
用途：平台架构
结构：中心平台 + 周边系统

## Pattern 007 Layered Architecture
用途：系统架构
结构：基础设施层、数据层、平台层、应用层、治理层

## Pattern 008 AI Workflow
用途：AI 工作流
结构：输入 → AI 分析 → 医生确认 → 报告输出

## Pattern 009 Governance Loop
用途：质控和合规
结构：标准 → 执行 → 记录 → 复核 → 改进

## Pattern 010 Roadmap Timeline
用途：实施路线
结构：阶段一、阶段二、阶段三、阶段四

## Pattern 011 ROI Value Bridge
用途：价值证明
结构：效率、质量、成本、科研、协同

## Pattern 012 Final Recommendation
用途：结论页
结构：三条建议 + 下一步行动

## Pattern 013 Diagnostic Accuracy Showcase
用途：AI 诊断性能展示
结构：灵敏度/特异度/ROC 曲线/AUC 值四宫格

## Pattern 014 Specimen Journey
用途：标本全流程展示
结构：取材→固定→包埋→切片→扫描→阅片→归档

## Pattern 015 Triage Alert
用途：AI 分诊预警
结构：危急/重要/正常三级 + 优先级排序 + 处理状态

## Pattern 016 Multi-Site Network
用途：多中心协作网络
结构：地图标注 + 参与数 + 病例量 + 响应时间

## Pattern 017 Regulatory Badge
用途：合规资质展示
结构：NMPA证/等保/临床评价逐项打勾徽章

## Pattern 018 Interoperability Matrix
用途：系统集成能力
结构：HL7/FHIR/DICOM/IHE × HIS/LIS/PACS 对接矩阵

## Pattern 019 TAT Improvement Bar
用途：报告时效改善
结构：传统TAT vs 数字化TAT 对比柱状图

## Pattern 020 MDT Decision Circle
用途：多学科协作
结构：病理+影像+临床+放疗+化疗+基因 圆桌

## Pattern 021 Biobank Linkage
用途：生物样本库对接
结构：样本采集→条码化→存储→申请→出库→数据关联

## Pattern 022 Outlier Attribution Tree
用途：异常案例归因
结构：假阳/假阴 → 原因分类 → 模型改进 → 效果验证

## Pattern 023 Maturity Radar
用途：成熟度雷达图
结构：NOAH/HIMSS/电子病历/智慧医院 多维评分

## Pattern 024 Cost Pie + Delta
用途：单例成本拆解
结构：人力+耗材+折旧+质控 饼图 + 改善幅度

## Pattern 025 Publication Pipeline
用途：学术产出管线
结构：病例→队列→统计→论文→投稿→发表

## Pattern 026 Patient Journey Map
用途：患者体验旅程
结构：开单→采样→等待→报告→复诊→随访 全链路

## Pattern 027 AI Ethics Differential
用途：AI 偏差分析
结构：种族/性别/年龄/设备分层性能差异 + 缓解措施

## Pattern 028 Future Vision Big Picture
用途：未来愿景大图
结构：AI自主读片→医生角色转变→全自动化→预防性病理

## Pattern 029 Executive Three Takeaways
用途：高层摘要
结构：三个结论卡片

## Pattern 030 Final Recommendation
用途：结论页
结构：三条建议 + 下一步行动
