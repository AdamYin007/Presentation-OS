# Presentation Pattern Library V1

## Pattern 001 Hero Statement
用途：封面或核心观点页
结构：一句强观点 + 副标题 + 大留白

## Pattern 002 Executive Three Takeaways
用途：高层摘要
结构：三个结论卡片

## Pattern 003 Why Now
用途：解释项目紧迫性
结构：趋势 + 压力 + 机会

## Pattern 004 Pain Point Cluster
用途：现状痛点
结构：3-5 个痛点卡片

## Pattern 005 From-To Transformation
用途：转型逻辑
结构：传统模式 → 数字化模式 → 智能化模式

## Pattern 006 Platform Hub
用途：平台架构
结构：中心平台 + 周边系统

## Pattern 007 Layered Architecture
用途：系统架构
结构：基础设施层、数据层、平台层、应用层、治理层

## Pattern 008 AI Workflow
用途：AI 工作流
结构：输入 → AI 分析 → 医生确认 → 报告输出

## Pattern 009 Governance Loop
用途：质控和合规
结构：标准 → 执行 → 记录 → 复核 → 改进

## Pattern 010 Roadmap Timeline
用途：实施路线
结构：阶段一、阶段二、阶段三、阶段四

## Pattern 011 ROI Value Bridge
用途：价值证明
结构：效率、质量、成本、科研、协同

## Pattern 012 Final Recommendation
用途：结论页
结构：三条建议 + 下一步行动
