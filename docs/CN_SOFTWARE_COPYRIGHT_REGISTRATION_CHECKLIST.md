## 1. Applicant Confirmation

- [ ] Confirm legal entity name (individual vs. company)
- [ ] Prepare ID/business license copy
- [ ] Confirm developer relationship (employee / contractor / commissioned / joint development)
- [ ] Attach employment contract, commission agreement, or work-for-hire documentation if applicable

## 2. Software Identification

- [ ] Software full name (Chinese + English, consistent with all documents)
- [ ] Version number (e.g., v1.0.0)
- [ ] Development completion date
- [ ] First publication status (published / unpublished)
- [ ] Hardware environment requirements
- [ ] Software operating environment (OS, runtime, dependencies)

## 3. Source Code Materials

Prepare source code excerpt (30 pages, first 30 + last 30 pages, or 60 consecutive pages):

- [ ] Each page contains ≤ 50 lines
- [ ] Total ≥ 3000 lines of source code
- [ ] Header includes: software name, version, page number
- [ ] Sensitive information redacted (API keys, passwords, internal URLs)
- [ ] Third-party open-source dependencies clearly identified and separated
- [ ] No customer data, test patient data, or personal information included

## 4. Documentation Materials

- [ ] User manual (with screenshots)
- [ ] Design specification / architecture document
- [ ] Functional description document
- [ ] Installation and deployment guide
- [ ] All documents must use consistent software name and version

## 6. Third-Party Dependencies

- [ ] List all third-party open-source components
- [ ] Record each dependency's license type
- [ ] Confirm no copyleft license (GPL/AGPL) conflicts with proprietary distribution
- [ ] Prepare dependency license summary table

## 7. Evidence Chain

- [ ] Git commit history showing development timeline
- [ ] Signed release tags with SHA-256 hashes
- [ ] IP evidence package (see `scripts/create-ip-evidence-package.sh`)
- [ ] Contributor list with IP ownership confirmation
- [ ] NDA/confidentiality agreements for developers
- [ ] Outsourced work delivery certificates (if applicable)

## 8. Submission Preparation

- [ ] Materials reviewed by qualified agent or attorney
- [ ] No sensitive information leaks in submitted materials
- [ ] Copyright registration form completed accurately
- [ ] Application fee prepared
- [ ] Submission channel confirmed (China Copyright Protection Center / CPA)

## 9. Important Notes

- Software copyright registration is **preliminary evidence** of ownership, not definitive proof.
- Registration does NOT replace a complete evidence chain for infringement disputes.
- Copyright protects expression, NOT abstract ideas, functional concepts, or technical principles.
- Keep original development records, meeting notes, and design documents as supplementary evidence.
- File registration promptly after development completion to establish priority.
