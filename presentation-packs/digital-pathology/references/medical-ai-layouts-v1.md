# Medical AI / Healthcare Digitalization Layout Library V1

## 01. Hero Message
用途：封面、核心观点页  
结构：大标题 + 一句话副标题 + 大留白/图片  
适合：战略观点、发布会、院长汇报开场

## 02. Three Pillars
用途：能力框架  
结构：三个并列能力模块  
适合：AI、软件、数据治理三大能力

## 03. Platform Hub
用途：平台架构  
结构：中心平台 + 周边系统  
适合：LIS、PACS、AI、数据中台、远程会诊

## 04. Medical Workflow
用途：医疗业务流程  
结构：从患者/标本到报告的流程线  
适合：病理、影像、检验、诊疗闭环

## 05. AI Pipeline
用途：AI 工作流  
结构：数据输入 → 模型分析 → 医生确认 → 报告输出  
适合：AI 辅助诊断、质控、科研

## 06. Before / After
用途：数字化转型对比  
结构：传统模式 vs 数字化模式  
适合：医院信息化、智慧病理、智慧影像

## 07. Capability Map
用途：能力地图  
结构：2x2 或 3x3 能力矩阵  
适合：平台功能展示

## 08. Layered Architecture
用途：系统架构  
结构：基础设施层、数据层、平台层、应用层、治理层  
适合：医院数字底座、AI 平台

## 09. Roadmap Timeline
用途：实施路径  
结构：阶段一、二、三、四  
适合：项目规划、招投标实施方案

## 10. Evidence Table
用途：循证支撑  
结构：观点、证据、来源、可信度  
适合：医疗 AI、法规、临床价值

## 11. ROI Value Bridge
用途：价值证明  
结构：效率提升、成本下降、质量改善、科研价值  
适合：院长汇报、投资汇报

## 12. Governance Framework
用途：合规与治理  
结构：数据安全、权限、日志、质控、CAP/15189  
适合：医院信息化、数字病理平台

## 13. Ecosystem Map
用途：生态系统  
结构：医院、科室、平台、AI、供应商、患者  
适合：区域医疗、医联体、远程会诊

## 14. Command Center
用途：医院运营驾驶舱  
结构：大屏/KPI/监控模块  
适合：智慧医院、运营管理

## 15. Comparison Matrix
用途：竞品对比  
结构：产品/厂商 × 关键能力  
适合：设备选型、软件平台对比

## 16. Maturity Model
用途：成熟度评估  
结构：Level 1 到 Level 5  
适合：医院数字化成熟度、AI 应用成熟度

## 17. Use Case Cards
用途：应用场景展示  
结构：多个卡片，每张一个场景  
适合：AI 诊断、质控、科研、教学、会诊

## 18. Data Flywheel
用途：数据闭环  
结构：数据 → AI → 应用 → 反馈 → 数据  
适合：AI 持续学习、科研数据资产

## 19. Risk Control Grid
用途：风险管理  
结构：风险类型 + 应对措施  
适合：合规、AI 模型风险、数据安全

## 20. Executive One Pager
用途：高层汇报  
结构：一句结论 + 三个证据 + 一个行动建议  
适合：院长、董事会、投资人

## 21. Digital Pathology Stack
用途：数字病理专用架构  
结构：扫描仪、LIS、阅片、AI、质控、归档、会诊  
适合：数字病理项目

## 22. Smart Hospital Blueprint
用途：智慧医院蓝图  
结构：临床、运营、科研、管理、数据底座  
适合：医院整体数字化

## 23. AI Governance Loop
用途：AI 治理  
结构：模型开发、验证、部署、监控、迭代  
适合：医疗 AI 合规

## 24. Region Collaboration Network
用途：区域协同  
结构：中心医院 + 基层医院 + 云平台  
适合：区域病理、医联体

## 25. Clinical Decision Support
用途：临床决策支持  
结构：数据输入 + AI提示 + 医生决策  
适合：AI 辅助诊疗

## 26. Product Positioning
用途：产品定位  
结构：目标客户、核心价值、差异化能力  
适合：产品路演

## 27. Tender Response Map
用途：投标响应  
结构：招标需求 → 我方能力 → 证明材料  
适合：投标文件/PPT

## 28. Quality Control Loop
用途：质控闭环  
结构：发现问题、记录、复核、改进  
适合：CAP、15189、病理质控

## 29. Research Enablement
用途：科研赋能  
结构：数据沉淀、病例检索、队列构建、AI分析  
适合：科研教学平台

## 30. Final Recommendation
用途：结论页  
结构：三条建议 + 下一步行动  
适合：汇报收尾
